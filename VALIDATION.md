# Проверка версии 0.1.0

Проверено 13 ноября 2026 года, Windows, Python 3.12.14.

- 6 автоматических тестов: все прошли (`python -m unittest discover -s tests -v`).
- `pip check`: конфликтов зависимостей нет.
- Проверены синтаксис модулей и отрисовка окна без подключения к Telegram.
- PyInstaller собрал portable Windows-приложение.
- Готовый exe прошёл автоматический запуск с `--smoke-test` и штатное закрытие
  с кодом 0, используя временную базу и без авторизации Telegram.
- ZIP содержит приложение, зависимости, документацию и собранные лицензии.

В ходе проверки исправлено включение несовместимой ICU DLL из стороннего
инструмента в PATH. Скрипт сборки очищает PATH на время упаковки.

Не проверено: вход в реальный Telegram, код/2FA, реальные чаты, сетевые
ограничения, доставка уведомлений Windows, запуск на другом чистом компьютере,
установка через Inno Setup. Скрипт установщика подготовлен, Setup.exe не собран.
Автообновление, цифровая подпись и восстановление пропущенных событий мониторинга
пока не реализованы. Это ранняя бета, а не подтверждённый стабильный релиз.
