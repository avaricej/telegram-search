# Chat Scout

Открытое десктопное приложение для поиска в доступных аккаунту чатах Telegram.
Windows — основная целевая платформа. Версия 0.1.0: ранняя бета.

## Возможности

- Авторизация личного аккаунта, код Telegram и двухфакторный пароль.
- Выбор нескольких групп / каналов, фильтр списка.
- Условия «любая фраза», «все фразы», «исключить»; разделитель `;`.
- Нормализация регистра, пробелов и `ё/е`. Поиск подстрок, не морфология и не ИИ.
- Поиск истории за период с ограничением числа проверяемых сообщений на чат.
- Мониторинг новых текстовых сообщений с отдельными уведомлениями без содержимого.
- Локальные результаты, исключение повторов одного chat_id/message_id, экспорт CSV.
- Ссылки на сообщения каналов и супергрупп; доступ по ссылке зависит от прав аккаунта.

## Запуск из исходников (PowerShell, Python 3.12)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\chat-scout.exe
```

Получите собственные `api_id` и `api_hash` в https://my.telegram.org → API
development tools. Введите их и телефон с кодом страны, нажмите «Подключить / войти».
При следующих запусках сохранённый API ID / Hash и сессия используются повторно:
достаточно нажать подключение. Пароль 2FA и телефон приложение не сохраняет.

Отметьте чаты, задайте условия и период. Пример:

| Поле | Значение |
|---|---|
| Любая фраза | `python; аналитик` |
| Все фразы | `удаленно; sql` |
| Исключить | `стажировка; бесплатно` |

Сообщение должно содержать одну из первых фраз, все обязательные и ни одной
исключённой. Пустые условия пропускают любой непустой текст. Скрипт не читает
секретные чаты и не обходит ограничения доступа.

## Ограничения беты

Поиск сканирует историю через `iter_messages`, а не серверный текстовый поиск:
это даёт одинаковые локальные правила для истории и мониторинга. Проверяются
последние N сообщений до конца выбранного периода, до его начала или лимита.
Если лимит исчерпан, результат может быть неполным. Увеличьте лимит или сузьте
период. Удалённые и недоступные сообщения не восстанавливаются.

Мониторинг работает до закрытия приложения. Крестик завершает приложение;
сворачивание оставляет его работающим. Значок в системной области используется
для уведомлений, это не фоновая служба. Условия фиксируются при включении:
для изменения остановите и снова включите мониторинг. Даты относятся только к
поиску истории. Пропуски после сна/отсутствия сети проверяйте поиском вручную.
Редактирования сообщений, OCR, голосовые и содержимое вложений не обрабатываются.
Список показывает до 2000 результатов, CSV экспортирует до 1 млн записей.

Сессия и API Hash хранятся через системный keyring. Совпадения и настройки — в
каталоге `platformdirs.user_data_path("ChatScout", appauthor=False)` (на Windows
обычно `%LOCALAPPDATA%\ChatScout`). База не зашифрована. См. SECURITY.md.
Приложение не включает LLM, телеметрию, сервер и Docker.

## Проверки и сборка

```powershell
.\.venv\Scripts\python.exe -m pip install -e '.[build]'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\scripts\build.ps1
```

Результат: `dist\ChatScout\ChatScout.exe` и `dist\ChatScout-Windows.zip`.
Распространяйте всю папку, не только exe. Python на компьютере пользователя не
нужен. Для установщика установите Inno Setup 6 и скомпилируйте
`scripts\installer.iss`. Установщик не удаляет пользовательские данные и сессии.
Сборки не подписаны цифровой подписью. Автообновление пока не реализовано.
CI `.github/workflows/check.yml` запускает тесты и создаёт ZIP для Windows.
Зафиксированные версии всех установленных зависимостей Windows находятся в
`requirements-windows.lock`; CI устанавливает их перед установкой приложения.
Сборка также выполняет изолированный запуск готового exe с `--smoke-test`:
без Telegram, с временной базой и автоматическим закрытием окна.

Перед публичным релизом: проверить вход и выход на реальном аккаунте,
паузы FLOOD_WAIT, отмену, переподключение, уведомления и запуск на чистой Windows;
сверить лицензии поставляемых Qt-модулей, добавить подпись релиза при наличии.
Тесты не используют реальный Telegram и не подтверждают эти сценарии.
